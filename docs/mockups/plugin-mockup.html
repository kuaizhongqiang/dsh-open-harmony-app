dsh-harmony

0.1.0Experimentalplugins.detail.badge · demo
dsh-harmony
bundle detail document · first section, no heading of its own · loaded from the installed bundle’s own files

dsh-harmony 是运行在 DSH Host 进程内的 Cordis 插件（apply(ctx)），随 webServer 启动一个仅由本机与已配对设备可达的 HTTPS 网关。

它负责移动工作区路径解析、一次性配对码、已配对设备的撤销、回环白名单、CA 指纹状态与版本缓存。所有配置都通过本页注入的 plugins.bundle.config 与 plugins.row.config 表单呈现，不另开后台站点。
